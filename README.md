# Eventify

Eventify is a community-driven web application that helps users discover social development events, create community service initiatives, join events, and keep track of their participation in one place.

## 🚀 Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* DaisyUI
* Better Auth
* MongoDB
* Express.js
* JWT
* React-Toastify

## ✨ Features

### 1. Explore Upcoming Events

Browse upcoming community service events with their titles, locations, event types, dates, and thumbnails.

### 2. Create Community Events

Create social development events by providing event details, including title, description, event type, location, date, and thumbnail image.

### 3. Join Community Events

Explore event details and join events that interest you. Joined events are saved so users can keep track of their participation.

### 4. Manage Created Events

View all events created by you, update event information, and delete events when necessary.

### 5. Track Joined Events

View all events you have joined, organized by event date, to keep track of your upcoming community activities.

### 6. Authentication and Profile Management

Create an account or sign in using email and password, Google, or GitHub. Users can also manage their profile information and sign out.

### 7. Responsive Interface

The application is designed to work smoothly across mobile, tablet, and desktop devices.

### 8. Light and Dark Theme

Switch between light and dark themes for a comfortable browsing experience.

## 📌 Project Overview

Eventify is designed to bring people together through community service and social development activities. With event creation, participation tracking, and event management features, users can discover meaningful initiatives and take part in making a positive difference in their communities.
